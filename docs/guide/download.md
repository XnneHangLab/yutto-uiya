# 📥 下载管理

## 🔍 解析

把 B 站链接（单视频 / 收藏夹 / 合集 / 多P）粘贴到输入框，点「解析」。

列表会一次性全部出现 —— 解析只获取标题、封面等列表信息，不逐个请求视频流，
所以又快又不容易触发风控；画质菜单因此显示完整档位，实际画质由下载时自动降级决定，
详见 [画质菜单与批量下载画质说明](/troubleshooting/quality-auto-downgrade)。

解析完成后会自动展开最后一项的详情和封面预览；每一项也可以手动点「查看封面」和「详情」。

## ☑️ 勾选与下载选项

- 支持全选，合集 / 多P 会显示为分组，可整组勾选、展开查看；
- 下载选项（视频 / 音频 / 封面 / 字幕 / 弹幕、画质、音质、音频格式）对**同一批**
  勾选的视频统一生效 —— 想给不同视频用不同画质，分几批下载即可；
- 画质放心选高：视频不支持时自动降级到它的最高档，不会失败。

## 🚦 下载队列

- 队列**串行执行**：同一时刻只有一个任务在下载，其余安静地显示「排队中」。
  这是刻意设计 —— 串行下载能显著降低触发 B 站风控的概率；
- 执行中的卡片有阶段行（解析中 / 写入附件 / 下载中 / 后处理中）和实时进度条
  （百分比 · 已下载 / 总量 · 速率）；
- 排队和执行中的任务都可以取消，完成后可以直接「打开文件夹」。

## 🛰️ 背后的 yutto server

解析与下载由一个随应用自动启动 / 退出的常驻 yutto server 完成，平时无感。
如果出现「与 yutto server 的连接已断开」，到 设置 → 环境状态 一键重启即可：
[server 连接断开 / 启动失败](/troubleshooting/serve-restart)。
