# ⚙️ 设置说明

## 🔍 环境配置

设置页面可以查看和配置运行环境：

| 项目 | 说明 |
|---|---|
| 🐍 Python | 需要 Python ≥ 3.11，通过 `uv` 管理 |
| 🎞️ FFmpeg | 用于合并音视频流，可自定义路径 |
| 📦 uv | Python 包管理器 |

如果环境检测不通过，可以手动指定可执行文件路径。

## 🎵 音频格式

支持以下音频输出格式：

- **m4a** — 默认格式，质量好体积小
- **mp3** — 兼容性最好
- **flac** — 无损格式
- **wav** — 无损无压缩

## 🔑 账号登录

通过扫码登录 Bilibili 账号，解锁高画质和大会员内容。

登录状态会保存在本地，下次启动无需重新登录。

## 🌐 代理设置

如果你的网络环境需要代理，可以在设置中配置。

也可以一键关闭系统代理，避免下载时出现网络问题。

## ⚡ 解析并发数

下载合集、收藏夹等批量内容时，应用会先逐个解析列表里的视频。

解析并发数控制同时解析多少个视频，默认为 8：

- 数值越大，解析越快，下载开始得越早
- 如果解析经常失败，可以调小一些（最小为 1，即逐个解析）

在「设置 → 一般设置」中修改，点击「保存并重新检测」后生效。
