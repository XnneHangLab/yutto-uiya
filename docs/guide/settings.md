# ⚙️ 设置说明

## 🔍 环境配置

设置页面可以查看和配置运行环境：

| 项目 | 说明 |
|---|---|
| 🐍 Python | 需要 Python ≥ 3.11，通过 `uv` 管理 |
| 🎞️ FFmpeg | 用于合并音视频流，可自定义路径 |
| 📦 uv | Python 包管理器 |
| 🛰️ yutto server | 解析与下载的常驻后台，随应用自动启动 / 退出，可一键重启 |

如果环境检测不通过，可以手动指定可执行文件路径。

## 🛰️ yutto server

解析与下载都由一个常驻的 yutto server 完成：应用打开时自动拉起、关闭时自动退出，
平时不需要关心它的存在。

「设置 → 环境状态」里可以看到它的运行状态和地址。如果解析 / 下载报
「与 yutto server 的连接已断开」，点旁边的「重启」即可恢复，详见
[server 连接断开 / 启动失败](/troubleshooting/serve-restart)。

## 💾 保存并重新检测

点击「保存并重新检测」除了写入配置，还会**自动重启 yutto server**，让下载目录、
FFmpeg 路径、Python 运行方式的修改立即生效。

::: warning 会中断进行中的任务
正在解析或下载时保存设置，这些任务会被切断（设置页会显示琥珀色提示，但不会拦截）。
建议等队列跑完再改设置。
:::

## 🎵 音频格式

仅音频下载支持以下输出格式：

- **m4a** — 默认格式，质量好体积小（直接保存原始音轨，无转码损耗）
- **mp3** — 兼容性最好（自动转码）
- **flac** — 无损格式（自动转码）
- **wav** — 无损无压缩（下载后本地转码）

## 🔑 账号登录

通过扫码登录 Bilibili 账号，解锁高画质和大会员内容。

登录状态会保存在本地，下次启动无需重新登录。

## 🌐 代理设置

默认勾选「禁用代理」，解析与下载将强制直连。

如需使用系统或环境代理，取消勾选即可切换为自动模式。

## ⚡ 解析并发数

下载合集、收藏夹等批量内容时，应用会并发解析列表里的视频信息。

解析并发数控制同时解析多少个视频，默认为 8，上限 16：

- 数值越大，解析越快
- 如果解析经常失败（风控 / 网络不稳），可以调小一些（最小为 1，即逐个解析）

在「设置 → 一般设置」中修改，点击「保存并重新检测」后，下一次解析 / 下载即生效。
