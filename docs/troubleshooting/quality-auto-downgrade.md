# 🎚️ 画质菜单与批量下载画质说明

## 🔍 现象

- 解析收藏夹 / 合集时，列表不再一条条增长，而是一次性全部出现；
- 画质菜单总是显示完整档位（最高到 8K），即使视频本身不支持这么高的画质；
- 同一批一起「下载所选」的视频，都会使用同一份下载选项（同一个画质、音质、格式）。

## 💡 原因

新版（yutto serve 架构）中，「解析」只获取每个视频的稳定信息：标题、封面、分 P 列表等，
**不再逐个请求视频的流信息**。流信息接口是最容易触发 B 站风控（-412）、也最耗时的接口 ——
以一个 50 个视频的收藏夹为例，旧版（2.1.0）解析要额外发 50 次这样的请求，列表才会一条条慢慢出现。

因此现在：

- 解析非常快，列表一次性全部出现；
- 解析阶段拿不到每个视频真实支持的画质，画质菜单只能显示完整档位；
- 真实画质在**下载时**才确定：以你选择的画质为上限，自动降级到该视频支持的最高画质。
  所以放心选 8K —— 视频不支持时会自动回落，不会下载失败。

::: tip 画质仍受登录状态限制
未登录最高只有 480P，1080P 以上需要登录，4K / HDR / 杜比需要大会员。
详见 [画质只有 360P](/troubleshooting/low-quality-360p)。
:::

## ✅ 想给不同视频用不同画质？

当前下载选项对同一批视频统一生效。想区分画质，可以分批下载：
先勾选一批、设置画质、点「下载所选」；再勾选另一批、换个画质、再下载。
