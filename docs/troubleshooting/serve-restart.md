# 🔌 yutto server 连接断开 / 启动失败

## 🔍 现象

- 解析或下载失败，控制台出现「与 yutto server 的连接已断开」；
- 或启动应用后提示 yutto server 启动失败，解析按钮一直不可用。

## 💡 原因

解析与下载由一个常驻后台的 yutto server 完成（随应用自动启动、随应用关闭退出）。
它可能因为 Python 环境损坏、被安全软件拦截或进程意外崩溃而离线。

## ✅ 解决

1. 打开 设置 → 环境状态，找到「yutto server」一行；
2. 点「重启」，状态恢复为运行中即可继续解析 / 下载；
3. 如果重启仍失败：
   - 检查同一页里 Python / uv 是否就绪，必要时重新同步环境（参考
     [uv sync 安装失败](/troubleshooting/uv-sync-failed)）；
   - 到控制台页查看 `[serve]` 开头的日志，按报错内容排查。

::: tip 这些是正常现象
切换工作目录、点「保存并重新检测」都会自动重启 server；下载任务住在 server 里，
所以重启会中断进行中的任务（设置页保存前会有提示）。
:::
