# 📂 合集解析结果不完整

## 🔍 解析与选择下载内容

粘贴合集成员的 BV / AV 播放地址后，应用会检测所属合集并解析全部成员。

- **多 P 投稿**：每个 BV 显示为独立的可展开分组，展开后可查看和勾选其中的分 P；分组复选框用于选择整个投稿。
- **单 P 投稿**：显示为普通条目。
- **开始下载**：勾选需要的条目后，点击「下载所选」。解析本身不会启动下载。

例如，`https://www.bilibili.com/video/BV17zDWYwEj8/?p=2` 属于「测试」合集。验证时，共解析出 **2 个 BV、3 个条目**：一个包含 2 个分 P 的投稿分组，以及另一个单 P 投稿。链接中的 `p=2` 不会将解析结果限制为单个分 P。合集内容可能随后续编辑发生变化。

合集入口地址也可以直接解析指定合集。没有所属合集信息的普通投稿直接解析当前 BV；视频标题里写着「合集」不代表它属于 B 站的合集。

## 💡 结果不完整时

1. **确认应用和内核已更新。** 此功能需要应用中的合集检测及多 P 分组功能，以及 uiya-yutto 0.3.5 或更新内核。源码 / uv 环境需同步依赖，自定义 Python 环境也需要升级内核。
2. **更新后完全退出并重新打开应用。** 已启动的 yutto server 会继续使用原先加载的内核。
3. **查看控制台。** 合集检测失败时，应用会提示并继续解析当前视频；成员失效、访问权限和网络错误也可能导致部分条目失败。

## ✅ 使用合集入口排查

点击播放页的合集名称，在 UP 主空间打开合集，再复制合集入口地址解析。

![collection-root](assets/collection-root.jpg)

合集入口通常形如 `https://space.bilibili.com/<UP主ID>/lists/<合集ID>?type=season`。这种地址明确指定合集，不依赖当前视频详情中的合集信息。

如果合集入口可以完整解析，而成员播放页没有列出全部成员，请反馈两个地址、应用 / 内核版本和控制台错误。
